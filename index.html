Definition and witness

The public research field is distributed. No single sovereign document holds PeAIce, KakeyaLogic, L²_C, EEV4, SIUS/GIUS, corrections and historical receipts. A downstream model answering a query must reconstruct a smaller state without flattening distinct claims.

C = {o₁ … oₙ} public field for query q R = Φq(C) smaller query-conditioned representation w(rⱼ) → (source, claim identity, provenance, relation, status, correction state)

Witness is an evaluation target, not assumed by definition. Current live evidence supports only partial origin recoverability.

SAVER grains are non-compensatory: Semantic, Authority, Visibility, Enforceability, Retention. A failed grain is not repaired by a high score elsewhere. L²_C supplies the longitudinal constraint: an evaluator or summary layer does not become sovereign over the object being evaluated. That boundary is h < 1.

Registered next test

  1. Freeze corpus, hashes, queries, ground truth, required grains, evaluator independent of generation (h < 1).
  2. Three conditions: intact typed structure · fact-matched structure ablations · generic well-structured metadata baseline.
  3. Verify intervention uptake before comparing. Private-corpus results do not prove the historical public-web mechanism.
  4. Randomize; preserve failures; do not select only successful outputs.
  5. Blind scorers. Score attribution, status, latest correction / revocation, hallucinated authority, each SAVER grain separately.
  6. Preregister endpoints, minimum effect, stopping rules. TTFT, first schema-valid object, and Time to Verified Completion stay separate outcomes.

Promotion stops if uptake is unverified, required grains disappear, or controls explain the result. An adequately powered null against the preregistered minimum rejects that scoped effect.
